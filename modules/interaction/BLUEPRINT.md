# World interaction framework

Status: **blueprint**. Do not auto-install.

## Requirements

Define an interaction contract driven by Tags/Attributes. Server must validate eligibility, distance/context when relevant, cooldown, and action state. Avoid one Script per object. Provide a game-specific adapter for actual actions.

## Delivery rule

Before implementing this blueprint in a game, read the current game GDD/feature spec, check whether the feature is in the active milestone, and verify current official Roblox documentation for platform APIs that can change.
