# Monetization

Status: **blueprint**. Do not auto-install.

## Requirements

Verify current official Roblox monetization APIs. Keep product/pass IDs in environment config. Server validates/grants entitlements and receipts. Never trust client purchase claims.

## Delivery rule

Before implementing this blueprint in a game, read the current game GDD/feature spec, check whether the feature is in the active milestone, and verify current official Roblox documentation for platform APIs that can change.
